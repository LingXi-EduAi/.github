## 我们在做什么

灵犀教育是一个面向教学全过程的智能教育平台。我们希望把 AI 能力落到教师和学生每天真正会遇到的场景里：备一节课、生成一份课件、布置一次作业、批改一批提交、发现一个学生的薄弱点，再给出下一步可执行的教学建议。

目前项目围绕两个核心角色展开：

- **教师端**：提供 AI 教案生成、AI 课件制作、智能出题、作业发布与批改、班级管理、教学资源管理和学情分析。
- **学生端**：提供 AI 助教答疑、知识点自测、学习资源、作业提交、学习小组和个人学情报告。

## 产品能力

| 模块     | 能力                                                   |
| -------- | ------------------------------------------------------ |
| 智能备课 | 根据教学目标、知识点和课程内容辅助生成教案与教学方案   |
| 课件中心 | 集成课件生成能力，支持快速制作课堂演示材料             |
| AI 出题  | 按知识点、题型和难度生成练习与测评内容                 |
| 作业中心 | 支持教师布置作业、学生提交作业、教师批改与反馈         |
| 学情分析 | 通过图表呈现作业完成率、成绩分布、参与度和重点关注学生 |
| 学习支持 | 为学生提供 AI 答疑、知识点自测、学习资料和小组协作入口 |

## 技术方向

我们正在持续探索：

- **AI 教育工作流**：把 Dify 等 AI 服务接入真实教学流程，而不是停留在单次问答。
- **教师效率工具**：围绕备课、课件、作业、批改和班级管理减少重复劳动。
- **学习数据可视化**：把学生表现转化为可理解、可行动的教学反馈。
- **双端协同体验**：让教师端和学生端围绕同一套课堂数据自然联动。
